# 2026-09 安全修复与验证总结

核查日期：2026-09-13。范围：SSH Launchpad v0.2.6 候选工作树，包含 Go
引擎、CLI/Wails 提权桥、前端、下载与发布脚本。该说明不代表 release 已发布
或远端 CI 已通过。原始发现/复现位于本地 `build/audit/`，不提交可能包含
设备身份或绝对路径的原始记录。

| A04 | 多命令动作的早期失败被最后成功掩盖 | 失败传播与 shell 故障注入测试 |
| A05–A07 | 失败/中断未记入恢复、恢复丢失原状态、取消同时杀掉回滚 | 写前意图、配置/key/ACL/服务/规则原状态恢复、独立于 Apply 取消的有界恢复 context |
| A08 | GUI/CLI/提权 helper 并发修改 | 系统级变更锁跨 authoritative re-plan、Apply、Rollback；延迟动作保持锁，不再创建脱管后台任务 |
| A09 | GUI 丢失失败 journal，提权恢复缺少绑定 | 保留失败 report，Windows elevated Rollback 绑定已审阅 journal 字节摘要，失败页就地提供恢复入口 |
| A10–A11 | 缺少 sshd 时修复被认证前置检查阻塞；下载配置被静默忽略 | 分阶段安装后重新 Check/Plan；不支持的依赖下载组合显式阻止 |
| A12 | 版本与发布元数据漂移 | 候选版本、脚本默认值、tag notes 及 CI metadata gate 对齐 |
| A13 | GUI 状态超时被误认为取消 | 持续追踪真实 helper 终态，执行期间阻止导航/重复操作；bridge 测试覆盖 |

## 本地验证

- `go test -p 1 -race ./...`、`go vet ./...`、staticcheck：通过。
- govulncheck：当前分析构建无报告的可达漏洞；不表示所有依赖模块无公告。
- ShellCheck：POSIX scripts 与 macOS launcher 通过。
- 前端 typecheck/build，Playwright **23 项通过**；测试命令先构建，避免旧 dist。
- Windows amd64 核心测试二进制经 PowerShell/WSL interop 原生运行通过；生成
  PowerShell 只做语法解析，真实动作以 mocks 替代。
- Windows/Linux/macOS 的 amd64/arm64 `CGO_ENABLED=0 go build ./...` 通过；
  这不是原生 GUI/系统服务验收。
- 截图检查包括浅色、深色、360px、准备、失败恢复、未完成验证和成功交付。

测试包使用 `-p 1`，因为独立测试进程共享真实系统 mutation lock。没有放宽
生产锁，包内 race 检测与锁竞争用例仍启用。不要同时运行另一套变更测试。

## 必须保留的边界与后续验收

1. **没有真实系统 Apply**：未对本机或远端 SSH、Tailscale、防火墙执行安装/变更；
   未运行新的 UAC 系统变更、NSIS 安装/升级或隔离 VM 端到端恢复验收。
2. **UFW raw rules 是已知盲区**：当前适配器只读取 `ufw status verbose`，不读取
   `before.rules` / `after.rules` 或整个 nftables/iptables 数据面。它不能发现
   status 未展示的额外放行；自定义 raw rules 的目标需人工核查/暂不作为已验收
   的安全收敛目标。不能把错误消息中的“review raw rules”描述为已自动检查。
3. **全局 SSH dump 不等于每连接认证结果**：支持保守配置子集；仍需控制端核对
   host fingerprint 并实际用公钥连接。TCP endpoint 可达不证明恢复通道独立。
4. **恢复只覆盖可逆动作**：软件安装、登录与外部策略可能残留；旧后台任务和未确认
   不可逆动作需要人工处理。恢复报告优先于界面按钮名称或进程退出码的直觉推断。
5. **Windows 导出权限**：Unix 私密临时文件与原子替换不等于 Windows DACL 验收；
   含 auth key 的卡片仍需保存在受控目录，不应据此宣称所有平台访问权限已证明。
6. **发布状态未证明**：候选代码推送不等于二进制发布。签名/公证、依赖模块公告、
   原生平台、VM/安装器 smoke、远端 CI 均是独立验收项。

本轮未使用子代理。生成物、实际设备配置、原始日志、密钥和 journal 不提交。
