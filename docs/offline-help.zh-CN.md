# SSH Launchpad 离线帮助

## 最简单的使用方法

Windows 桌面用户优先下载安装器，双击安装后按中文向导操作。服务器或无桌面环境请完整解压 portable ZIP，再双击 `开始使用 SSH Launchpad.cmd`。

## 公钥不要弄反

- 正在设置的是“被连接电脑”。
- 需要提供的是“控制电脑”的 `.pub` 公钥。
- 私钥没有 `.pub` 后缀，必须留在控制电脑上；不要复制、粘贴、上传或放进 profile。
- 第一次从控制电脑连接时，要核对主机指纹，不要静默接受未知指纹。

## 没有网络

工具本身可离线运行。下载工具时，可通过 bootstrap 命令选显式代理/HTTPS 镜像，或使用带 `checksums.txt` 的离线发布资产；这不代表 profile 的同名设置会传给依赖包管理器。

缺少依赖时，目前只有 Windows Tailscale 支持固定 SHA-256 的 `offlineBundle`。OpenSSH 应先用平台可信安装机制离线装好，再重新检查；不支持的组合会被 Plan 阻止。不要关闭 TLS 或系统安全软件绕过校验。

## 管理员授权、取消和恢复

Windows GUI 可由普通用户启动，仅实际变更/恢复时请求 UAC；Unix CLI 的管理员要求按命令提示处理。取消授权后不会继续执行。

部分失败会停止后续步骤；自动恢复启用时尝试恢复可逆改动。失败页和高级选项可导出诊断报告或选择“恢复可逆改动”。软件安装/登录可能无法撤销；先查看恢复结果，不要盲目重跑。界面仍显示执行中时不要关闭窗口或重复启动。

## 远程运行安全

若当前唯一连接正依赖 SSH/Tailscale，工具默认阻止可能让自己断线的操作。请到目标机本地执行、准备第二条通道，或从另一台电脑完成外部验证。

`--schedule-risky` 是持有变更锁的进程内延迟，不是后台任务；需保持进程运行。旧版 scheduled journal 必须人工确认后台任务已停止后处理。UFW 自定义 raw rules 未被完整自动检查。

完成页表示本机检查通过，还需从控制电脑核对主机指纹并实际用公钥试连。

当前版本未代码签名。遇到系统警告时请先核对 Release 页的 SHA-256，不建议关闭 SmartScreen 或安全软件。
